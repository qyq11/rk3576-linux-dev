# 烧录工具

这里放电脑连接板卡并写入固件所需的工具，不作为正式程序源码目录。安装包与解压内容不随Git保存；这份README用于说明目录职责。

[返回上级说明](../README.md)

## 文件用途

| 文件或目录 | 用途 |
| --- | --- |
| [configs](configs) | 当前有TaishanPi-3M-RK3576_Linux.cfg板卡烧录配置；正式归档的配套配置另见07_backups。 |
| [RKDevTool_v3.37_for_window](RKDevTool_v3.37_for_window) | 已解压的Windows Rockchip烧录工具。 |
| [RKDevTool_v3.37_for_window.zip](RKDevTool_v3.37_for_window.zip) | 上述工具的原始压缩包。 |

使用前按[操作记录](../../02_records/README.md)确认适用环境和步骤。烧录镜像及匹配恢复配置查[正式归档](../../07_backups/README.md)，不能仅凭这里有工具就判断可直接写板。
