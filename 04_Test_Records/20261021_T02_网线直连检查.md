两端属于 `192.168.100.0/24`，地址不同。仅用于此网线两端通信时，板端无需为该接口添加默认网关或 DNS。此规划不包含 Windows 网络共享，也不据此判定开发板能够访问互联网。

本记录建立时的旧照片显示 `end0` DOWN 且无地址；后续新照片已确认 end0 UP / LOWER_UP 和 NetworkManager，见 [板端新状态记录](20261021_T02_直连网口与网络管理状态.md)。

## 4. 下一步在板卡本地执行

```bash
ip link show end0
ip -br addr
nmcli device status
```

- 第一条查看接口管理状态、物理链路标志及 MAC。
- 第二条确认接线后是否已经有地址，避免重复添加。
- 第三条识别 NetworkManager 是否存在并管理 `end0`；如命令不存在，保留提示后切换到实际管理工具。

上述查询现已完成，NetworkManager 管理 end0 已确认，具体配置见 [直连固定 IP 配置步骤](../02_Study_Notes/直连固定IP配置.md)。随后依次验证 IP 互通、SSH 端口与登录，并在重启后复测持久性。当前 T02 保持进行中。
