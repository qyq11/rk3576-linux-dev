# 第05轮人工观察记录模板

仅使用原配置、原资料、已有真实账户。先填发布编号、板B序列号、场景目录、观察人及时间；不记口令。无人实际操作的项目保留待验。原登录同步范围未确认时，不执行在线真实认证。每项保存“实际操作、看到的结果、对应日志/屏幕证据、通过或待验”，不只填一个总勾。

| 操作 | 观察点 | 本次结果 |
| --- | --- | --- |
| 启动后先看机型下方文字和原启动动画 | 卡片完整可见，文字不被裁切；GIF确有帧推进。公司Logo本来是静态PNG，不能把它当缺失GIF | 待实际观察 |
| 旁观自动专项的真实TCP断开阶段，不点任何按钮 | 显示等待连接；灰灯完整由浅到深再到浅，并持续闪烁 | 待实际观察 |
| 用已有管理员账号在原卡片输入密码，不勾“默认” | 认证来源、角色名称和显示身份符合原角色字典；口令不进入记录 | 待实际操作 |
