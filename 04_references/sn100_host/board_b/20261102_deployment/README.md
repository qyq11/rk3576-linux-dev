## 文件怎样核对

`install.log`、`preflight.log`和`*_ssh_exit.txt`保存实际上传/检查输出及退出码，`current_source_snapshot.json`记录部署前输入。`screen_runs/`按每次启动保存程序/显示日志、退出结果和资源采样；`offscreen/`是板B无屏幕检查，不代替实际画面。`final_environment.txt`是取证时的运行快照。

`time_correction.log`、`rtc_correction.log`和`rtc_sync_result.log`分别是系统校时、缺命令失败和最终硬件时钟写入回读；`rtc_sync.c`为临时工具源码，`.sh`为实际执行脚本。没有归档数据库、临时初始化密码或认证文件。

`SHA256SUMS`登记本目录除说明外的证据，可在WSL进入本目录执行`sha256sum -c SHA256SUMS`。安装与恢复输入复用[既有正式归档](../../../../07_backups/sn100_host/reagent_calendar_20261030/README.md)，没有重复备份整机或覆盖已有数据。
