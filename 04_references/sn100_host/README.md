## 优先看什么

原文件用途和数据库沿用依据见[original_bin_20261027/](original_bin_20261027/README.md)：包含截图所指305个文件的指纹、29库结构和算法/日志库的对外函数。这里只保存静态依据，不含原库业务记录，也不代表RK已接入原库。

本次直接读写与INI兼容的RK运行证据见[original_db_20261027/](original_db_20261027/README.md)：29库原样复制检查、134项INI读取一致、后端90项与实际页面114项通过，以及原失败、修复和资源采样；未归档原患者或认证资料。

先看[同一移植记录](../../02_records/20261022_sn100_host_migration.md)找到当批结论及源码范围，再打开它指定的`verification.json`、`handoff.json`、`checkpoint_index.json`或具体日志；每批不一定都有这些文件。

`SHA256SUMS`或哈希字段用来核对文件身份，`source_snapshot.json`或输入清单说明测的是哪份源码，`.log/.txt`保留实际输出，`.json/.csv`常保存结构化结果/采样。子目录里的驱动源码是复现证据，不应当作正式业务源码修改。固定批次内容及清单保持原样，新工作另按原事项追加。

当前用户操作看[手动测试说明](../../01_docs/knowledge/sn100_host_manual_test_guide.md)，应用/源码恢复包看[正式归档](../../07_backups/sn100_host/README.md)。
