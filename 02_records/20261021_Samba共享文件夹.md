## 2. 配置共享

备份配置：

```bash
sudo cp -a --backup=numbered /etc/samba/smb.conf /etc/samba/smb.conf.before-rkshare
```

打开编辑器：

```bash
sudo nano /etc/samba/smb.conf
```

按 **Alt+/** 到末尾，另起一行；复制下面的配置，用 **Ctrl+Shift+V** 粘贴。已有 `[rkshare]` 时修改原段，避免重复。

```ini
[rkshare]
    path = /home/rkshare
    browseable = yes
    read only = no
    guest ok = no
    valid users = lckfb
    create mask = 0600
    directory mask = 0700
```

**Ctrl+O → 回车**保存，**Ctrl+X**退出。检查配置：

```bash
sudo testparm -s
```

初次配置检查返回 `Loaded services file OK.`；上方配置已更新为迁移后的路径。

设置开机启动：

```bash
sudo systemctl enable smbd
```

加载配置并启动服务：

```bash
sudo systemctl restart smbd
```
