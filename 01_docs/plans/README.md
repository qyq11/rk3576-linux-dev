# 计划怎么读

日常先看下一步清单；需要了解依赖和验收范围时，再打开整体计划或SN100移植计划。三份文件分工不同，不代表三条互不相关的开发线。

[返回上级说明](../README.md)

## 文件用途

| 文件或目录 | 用途 |
| --- | --- |
| [next_steps.md](next_steps.md) | 日常入口：当前优先事项、下一步和启动条件。 |
| [development_plan.md](development_plan.md) | 整个RK3576项目的路线：实时内核、业务与接口、调度/算法/界面验证、联调和环境定版。 |
| [sn100_host_migration_plan.md](sn100_host_migration_plan.md) | SN100具体功能、依赖、当前实施卡、待补资料，以及电脑/RK/真实仪器各自的验收任务。 |

## 更新方式

计划保留“已完成、当前需要做、未完成即将执行、将来需要做”四部分和勾选框。实际过程写入对应[操作记录](../../02_records/README.md)，这里保留状态、下一步及证据入口；本目录README只解释文件用途。
