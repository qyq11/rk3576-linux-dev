## 1. 安装与目录权限

以下命令在 **WindTerm 的板端终端**执行。第 1、2 节供新建共享复现；已有共享迁移见第 6 节。

更新软件源：

```bash
sudo apt update
```

安装：

```bash
sudo apt install samba
```

查看版本：

```bash
smbd --version
```

创建目录：

```bash
sudo mkdir -p /home/rkshare
```

设置所有者：

```bash
sudo chown lckfb /home/rkshare
```

设置权限：

```bash
sudo chmod 700 /home/rkshare
```

检查权限：

```bash
ls -ld /home/rkshare
```

迁移前原目录的实际输出（保留原文）：

```text
drwx------ 2 lckfb root 4096 Oct 21 15:52 /srv/samba/rkshare
```

登记 Samba 账号，输入两遍共享密码：

```bash
sudo smbpasswd -a lckfb
```

实际返回 `Added user lckfb.`。这是为已有 Linux 用户开通共享登录；Samba 密码单独管理，不写入记录。

## 2. 配置共享

备份配置：

```bash
sudo cp -a --backup=numbered /etc/samba/smb.conf /etc/samba/smb.conf.before-rkshare
```

打开编辑器：

```bash
sudo nano /etc/samba/smb.conf
```

按 **Alt+/** 到末尾，另起一行；复制下面的配置，用 **Ctrl+Shift+V** 粘贴。已有 `[rkshare]` 时修改原段，避免重复。

```ini
[rkshare]
    path = /home/rkshare
    browseable = yes
    read only = no
    guest ok = no
    valid users = lckfb
    create mask = 0600
    directory mask = 0700
```

**Ctrl+O → 回车**保存，**Ctrl+X**退出。检查配置：

```bash
sudo testparm -s
```

初次配置检查返回 `Loaded services file OK.`；上方配置已更新为迁移后的路径。

设置开机启动：

```bash
sudo systemctl enable smbd
```

加载配置并启动服务：

```bash
sudo systemctl restart smbd
```

## 6. 迁移至 home（已完成）

用户确认迁移完成，Windows 可见以下两个目录并正常读写。目录结构为说明示意：

```text
/home/rkshare/
├── gpio/       # 原共享中的工程文件
└── lckfb/      # 整个用户主目录
```

迁移前已确认原共享与主目录均位于 `/dev/root`。操作顺序：备份 `/etc/samba/smb.conf` 为 `smb.conf.before-home`，进入 `/` 并停止 `smbd`，再移动目录：

```bash
sudo mv -vnT -- /srv/samba/rkshare /home/rkshare
```

```bash
sudo sh -c 'mv -vnT -- /home/lckfb /home/rkshare/lckfb && ln -svT -- /home/rkshare/lckfb /home/lckfb'
```

以上为旧布局的一次性迁移步骤，已完成后不重复执行。`/home/lckfb` 按方案保留为指向 `/home/rkshare/lckfb` 的兼容链接，登录仍沿用原路径。

最后将 `[rkshare]` 的 `path` 改为 `/home/rkshare`，按第 2 节检查配置并重启服务。Windows 继续使用 `\\192.168.100.123\rkshare`，账号不变。
