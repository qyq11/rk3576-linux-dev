`build_integration_07.sh` 先完成只读输入检查，再排他新建本批输出目录。它拒绝已有目录，明确清除对象复用入口，使用现有配套环境、Release 和 jobs=2 完整构建主程序与报告辅助程序；缺已有环境即停。退出处理保存真实失败码，未到完整收尾却退出 0 时改为 125，并等待日志写完。`verify_integration_07_inputs.py` 核实际五类构建输入、完整源码前后指纹、动态对象集合与 ARM64 文件头、两个程序、依赖报告和包身份，完整通过才生成构建完成记录。

`stage_board_b_release_07.py/.sh` 只认本批实际构建退出 0、完整构建记录及同一包，先只读回核包内源码、两程序和依赖身份。网络固定板 B 公钥、硬件序列号和有线地址；两次动作都核仍为第六批 current。上传用排他新包名，开始记录在网络动作前落盘，上传和保存各自保存真实日志与退出码；缺标记、依赖缺失或输入变化不登记完整完成。远端取得部署锁后重新核身份、current、包及目标，拒绝已有版本，仅建立独立版本目录；不切 current、不启停程序。正常成功才清理本轮已核上传包和空暂存目录，失败保留现场。
