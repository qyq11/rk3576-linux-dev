# 原配置数据库在RK上的页面截图

这些图片由RK上的Qt页面抓取，来自原项目库的直接读写验证；物理屏幕目视和触屏操作仍另验。项目名及参数属于用户已授权沿用的项目配置，没有患者或账户内容。

- `original_base`：原七项目、基础参数与原单位。
- `original_parameters`：完整基础键值及91项算法参数的查看入口。
- `original_results`：原五行结果；MDA及未知规则保留只读。
- `original_units`：原单位类型和实数倍率。
- `final_page`：测试结束并恢复草稿后的项目页面。

文件均以`20261027_original_db_`开头。实际操作、数据核对和剩余限制见[同一移植记录](../../../02_records/20261022_sn100_host_migration.md#original-db-rk-20261027)；逐项结果在[验证证据](../../../04_references/sn100_host/original_db_20261027/)中。
