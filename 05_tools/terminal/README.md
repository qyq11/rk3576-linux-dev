# 终端工具

这里放访问Windows、WSL、SSH或串口的终端工具，不作为正式程序源码目录。安装包与解压内容不随Git保存；这份README用于说明目录职责。

[返回上级说明](../README.md)

## 文件用途

| 文件或目录 | 用途 |
| --- | --- |
| [MobaXterm_Installer_v26.5](MobaXterm_Installer_v26.5) | 已解压的MobaXterm安装文件；该工具用于SSH、串口等终端访问。 |
| [MobaXterm_Installer_v26.5.zip](MobaXterm_Installer_v26.5.zip) | 上述安装文件的原始压缩包。 |
| [windterm](windterm) | 本机WindTerm工具目录；项目中的WSL与RK会话调整见工作目录记录。 |

使用前按[操作记录](../../02_records/README.md)确认适用环境和步骤。烧录镜像及匹配恢复配置查[正式归档](../../07_backups/README.md)，不能仅凭这里有工具就判断可直接写板。
