# 新板CAN0配置与有限回退输入

来源：2026-11-02按用户接口图配置的新板，立创泰山派3M RK3576，`6.1.99-rt36-tspi #2`。本轮只新增CAN0小配置，修改两个配置清单；未烧录分区镜像。CAN0及7/11脚复用重启核对通过，发送确认通过，独立接收及外部硬件尚未通过。[实际记录](../../../02_records/20261102_can.md)。

| 文件 | 用途与恢复位置 |
| --- | --- |
| `overlays.ini.before` | 写入前的`/boot/overlays/overlays.ini` |
| `ubootenv.before` | 写入前的`/boot/overlays/.ubootenv` |
| `overlays.ini.after`、`ubootenv.after` | 本轮启用并重启后实际取回的两个文件 |
| `can0_m2.dts`、`tspi-3m-can0-m2.dtbo` | 本轮小配置源码及已安装文件；目标为`/boot/overlays/tspi-3m-can0-m2.dtbo` |
| `SHA256SUMS` | 本目录文件指纹，比较复制前后内容是否一致 |

回退范围只有CAN0本轮小配置，不是整机或内核备份，不涉及SSH密钥、密码或其他认证资料。首轮配置因工具查询权限失败时，自动恢复前两个文件并删除本轮新文件，下一轮写入前与原指纹比较一致；这是本轮错误处理中实际完成的恢复，不等于其他环境的恢复测试。

若只想停用本轮CAN0配置，使用官方工具停用后重启，不覆盖后续其他接口新增的条目：

```bash
sudo ovtree --lang zh disable tspi-3m-can0-m2.dtbo
```

```bash
sudo reboot
```

本轮未执行最终停用重启：当前CAN0小配置仍启用，通信接口保持停止。若需逐字节恢复最初两个清单，先确认期间没有其他配置新增，再把两个`.before`文件分别恢复至表中的原路径、删除本轮新增的同名小配置并重启。不能直接用旧清单覆盖后续新增的UART、显示或其他配置。
