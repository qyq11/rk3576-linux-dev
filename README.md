更新日期：2026-10-21。系统声明 Ubuntu 24.04.5 LTS，运行 Linux 6.1.99 / aarch64；Windows 网线直连地址为 192.168.100.200/24，板端固定地址 192.168.100.123/24 已生效并通过本次重启验证。Windows ping 4/4 回复，SSH 22/TCP 可达；下一步验证 lckfb 账号远程登录。

## 3. 从哪里开始

1. 型号与系统摘要已记录，继续补齐硬件版本及原理图信息。
2. 已建立 HDMI 本地命令行入口，使用 `lckfb` 账号登录，完成系统和网络初查。
3. 确认 Windows 与板卡的网络连接，完成固定 IP 和 SSH 登录，并验证重启后仍有效。
4. 确认“第八个 TTL”的接口含义，完成目标串口输出及串口扩展。
5. 验证开机输出、输入及回环测试，保存接线、配置和收发证据。

详细步骤与任务状态统一维护在任务清单中。固定 IP 和重启验证已通过，下一步在 Windows PowerShell 执行 `ssh lckfb@192.168.100.123` 并验证远程命令，见 [最新测试记录](04_Test_Records/20261021_T02_固定IP重启与SSH端口验证.md)。

## 6. 后续维护约定

- 一级目录使用“连续两位编号 + 英文用途名”，现有编号为 01–05；后续有实际内容时再增加目录。
- 删除文件夹后重新整理剩余目录的编号和命名，同步更新本 README 的目录结构、说明和链接，以及其他受影响的引用。
- 参考资料放 `01_References/`，操作步骤和学习笔记放 `02_Study_Notes/`，实际测试结果放 `04_Test_Records/`。
- 中文笔记使用简洁主题名；测试记录使用 `YYYYMMDD_任务编号_主题.md`，例如 `20261021_T02_网线直连检查.md`。
- 开发图片按“日期_图片内容_序号”命名；所有任务图片统一直接放在 `05_Photos/`，不按任务建立图片子目录，保留图片原文件。
- 照片原文、解析推断和实际测试结论分开记录；看不清或未验证的内容明确标注。
- 形成正式源码与可复用程序时再建开发目录；需要一次性整理程序和中间产物时再建 `temp/`，清空后移除。
- 配置示例不保存密码、私钥等凭据。
- 原有[开发流程笔记](02_Study_Notes/Linux开发流程.md)还包含 Samba、实时内核等历史规划，本次未将它们新增为必做任务。
