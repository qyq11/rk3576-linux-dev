# 驱动工具

这里放电脑侧USB、串口或烧录设备驱动相关工具，不作为正式程序源码目录。安装包与解压内容不随Git保存；这份README用于说明目录职责。

[返回上级说明](../README.md)

## 文件用途

| 文件或目录 | 用途 |
| --- | --- |
| [DriverAssitant_v5.14](DriverAssitant_v5.14) | 已解压的Rockchip驱动助手，供Windows识别烧录相关USB设备。 |
| [DriverAssitant_v5.14.zip](DriverAssitant_v5.14.zip) | 上述驱动助手的原始压缩包。 |
| [PL2303TA_3.8.36.2](PL2303TA_3.8.36.2) | PL2303TA USB转串口驱动文件，用于相应串口适配器。 |

使用前按[操作记录](../../02_records/README.md)确认适用环境和步骤。烧录镜像及匹配恢复配置查[正式归档](../../07_backups/README.md)，不能仅凭这里有工具就判断可直接写板。
