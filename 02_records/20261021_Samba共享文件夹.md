2026-10-21｜泰山派 3M RK3576 / Ubuntu 24.04｜**配置、登录及双向传输通过，用户已确认；重启复测待完成。**

| 项目 | 参数 |
| --- | --- |

## 1. 安装与目录权限

以下命令在 **WindTerm 的板端终端**执行，复现时按顺序操作。

更新软件源：

```bash
sudo apt update
```

安装：

```bash
sudo apt install samba
```

查看版本：

```bash
smbd --version
```

创建目录：

```bash
sudo mkdir -p /srv/samba/rkshare
```

设置所有者：

```bash
sudo chown lckfb /srv/samba/rkshare
```

设置权限：

```bash
sudo chmod 700 /srv/samba/rkshare
```

检查权限：

```bash
ls -ld /srv/samba/rkshare
```

已提供的实际输出：

```text
drwx------ 2 lckfb root 4096 Oct 21 15:52 /srv/samba/rkshare
```

登记 Samba 账号，输入两遍共享密码：

```bash
sudo smbpasswd -a lckfb
```

实际返回 `Added user lckfb.`。这是为已有 Linux 用户开通共享登录；Samba 密码单独管理，不写入记录。

## 2. 配置共享

备份配置：

```bash
sudo cp -a --backup=numbered /etc/samba/smb.conf /etc/samba/smb.conf.before-rkshare
```

打开编辑器：

```bash
sudo nano /etc/samba/smb.conf
```

按 **Alt+/** 到末尾，另起一行；复制下面的配置，用 **Ctrl+Shift+V** 粘贴。已有 `[rkshare]` 时修改原段，避免重复。

```ini
[rkshare]
    path = /srv/samba/rkshare
    browseable = yes
    read only = no
    guest ok = no
    valid users = lckfb
    create mask = 0600
    directory mask = 0700
```

**Ctrl+O → 回车**保存，**Ctrl+X**退出。检查配置：

```bash
sudo testparm -s
```

本次返回 `Loaded services file OK.`，共享路径、账号和可写设置正确。

设置开机启动：

```bash
sudo systemctl enable smbd
```

加载配置并启动服务：

```bash
sudo systemctl restart smbd
```

## 3. Windows 登录

在 **Windows PowerShell** 执行；`*` 保持原样，按提示输入 Samba 密码：

```powershell
net use \\192.168.100.123\rkshare * /user:lckfb
```

用户确认命令成功。在 **Windows 文件资源管理器地址栏**打开：

```text
\\192.168.100.123\rkshare
```

首次直接访问曾出现“扩展错误”（[原图](../03_photos/20261021_Samba共享访问扩展错误_01.png)）。445 端口检查通过，显式指定 `lckfb` 后可打开共享；最初失败的具体原因未单独追溯。

## 4. 双向传文件实验

**用户已确认两个方向传递成功。** 以下保留测试内容与复现方法，未将示例文本作为终端原始输出。

### Windows → RK

在 Windows 项目的 `temp/` 中准备 `samba_pc_to_rk.txt`，内容如下：

```text
PC_TO_RK_0001: Hello from Windows
PC_TO_RK_0002: Samba upload test
PC_TO_RK_0003: END
```

将文件复制到共享窗口，在 **WindTerm** 读取并与原文件核对：

```bash
cat /srv/samba/rkshare/samba_pc_to_rk.txt
```

### RK → Windows

在 **WindTerm** 生成另一份测试文件：

```bash
printf '%s\n' 'RK_TO_PC_0001: Hello from RK3576' 'RK_TO_PC_0002: Samba download test' 'RK_TO_PC_0003: END' > /srv/samba/rkshare/samba_rk_to_pc.txt
```

查看内容：

```bash
cat /srv/samba/rkshare/samba_rk_to_pc.txt
```

测试内容：

```text
RK_TO_PC_0001: Hello from RK3576
RK_TO_PC_0002: Samba download test
RK_TO_PC_0003: END
```

Windows 刷新共享窗口，将该文件复制到项目本地 `temp/`，打开本地副本，与板端内容核对。
