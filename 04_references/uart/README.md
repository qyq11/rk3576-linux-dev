## 两块板怎么区分

2026-11-02用户确认两块是不同实物、同一型号。此前开发用的记为板A，用于现有Qt上位机；另一块记为板B，留作后续其他用途。下表“本轮”指2026-11-02串口检查与配置，历史资料不批量改名或移动。[项目统一记录规则](../../02_records/20261021_ai_workflow.md#two-board-records)。

新日志先放`temp/uart/<board_a或board_b>/<日期与事项>/`，需要长期保存的实际证据放本目录对应板卡子目录。每次记录板卡标记、能读取的硬件序列号、系统/内核和连接身份；重新烧录可能改变SSH指纹，变更时核对实际板卡并追加说明。两块板沿用同一IP时，每次仍须核清连接的是哪一块。
