## 使用和原版依据

选择试剂孔位，打开孔位设置，点击有效期旁日历；翻月后选择日期，再保存孔位。关闭日历不改原值，取消孔位会放弃刚选日期，空日期不会自动增加一年。名称顺序为none（不配置试剂）→有效清洗液→本区域有效试剂；组内保留读到的原表顺序，不按名称另排序。

原只读依据为`MaskDlgReagentSetting::refreshCurrentHole/on_btnCalendarSet_clicked`和`ReagentListTable::getReagentNameListByType`。入口是`ReagentsPage::openHoleEditor`，日历复用已有CusCalendar、原cusmaskcalendar.ui、遮罩和箭头，选中输出`yyyy/MM/dd`，取消不写；日历赋值明确标记未保存草稿。日历打开时注销禁用操作，恢复身份后按钮恢复；不改变孔位更新命令、原批组规则或数据结构。具体原件及当前UI指纹见`behavior_review.json`。
