## 新原RX链的实际约束

1. 查询BEGIN/END唯一且同代，明确Qk TX最多一次；原TX块逐份与检查器记录比较，Qk记录代次须与该区间相同。原包没有连接代次字段，工具如实说明代次仍来自本次真实信号及日志元数据，未声称可从字节推出代次。
2. 当前消息必须完整落在实际行区间；跨BEGIN/END、Qk发送时已有当前消息半帧、或字节到达与回调分发先后不能对应时保留pending。全流末尾未收齐也不补造消息。头内原payload必须是该窗口真实消息的有序前缀，允许头内冻结后到END前的实际迟到消息另列，不用它们补齐已冻结头记录。
3. CSV来源固定为本轮原资料的`db/systemInfo/abnormal_Config.csv`。runner保存启动前SHA并在结束校验；collector只额外读取这一份非患者规则，限制4MiB、拒链接/重定向、核启动和采集前后同SHA，保留原文/本地SHA与编码。独审再次检查这些字段、结束OK及实际原件SHA；缺失、变化、脱敏或无损解码不成立时不记映射通过。
4. CSV按原列、原trim/引号、原首匹配顺序读取，不按enabled或动作过滤显示；Qk按实际原参数及原1至5参数规则展开，未知/空说明按编号与原参数拼接。QK直接核主控原说明/措施和编号星号。产品观察还核原编号/数量/顺序/接收时间；表内行必须来自已独核观察，按原说明去重并包含最后一批说明。
