/*
 * Copyright (c) 2025 LCKFB <lckfb@sz-jlc.com>
 * TaishanPi-3M RK3576 40Pin Header Configuration
 *
 * DEFAULT ACTIVE FUNCTIONS:
 * =========================
 * Pin 3/5  (GPIO3_A1/A0): I2C7_M1
 * Pin 8/10 (GPIO2_D0/D1): UART4_M0
 * Pin 12   (GPIO0_B5):    PWM1_CH1_M0
 * Pin 19/21/23/24/26 (GPIO2_C2/C3/C5/C4/C1): SPI1_M1 (MOSI/MISO/CLK/CSN0/CSN1)
 * Pin 27/28 (GPIO2_B7/B6): I2C8_M2
 * Pin 32   (GPIO2_C7):    PWM0_CH1_M2
 * Pin 33   (GPIO4_A7):    PWM2_CH6_M0
 * Pin 35   (GPIO0_D2):    PWM1_CH5_M0
 *
 * GPIO-ONLY PINS (no mux function active):
 * =========================================
 * Pin 7  (GPIO4_A6), Pin 11 (GPIO4_A4), Pin 13 (GPIO2_C6),
 * Pin 15 (GPIO0_C7), Pin 16 (GPIO0_C6), Pin 18 (GPIO3_A3),
 * Pin 22 (GPIO2_D6), Pin 29 (GPIO2_C0), Pin 31 (GPIO2_B0),
 * Pin 36 (GPIO2_D7), Pin 37 (GPIO2_A6), Pin 38 (GPIO3_A2),
 * Pin 40 (GPIO2_A7)
 *
 * PIN CONFLICT GUIDE:
 * ===================
 * Pin 3/5 (GPIO3_A1/A0):
 *   - I2C7_M1 (enabled) vs UART3_M0 vs SPI3_MOSI/CLK_M0
 *   - To use UART3: disable i2c7, enable uart3
 *   - To use SPI3: disable i2c7, enable spi3 (also needs pin 18/38)
 *
 * Pin 8/10 (GPIO2_D0/D1):
 *   - UART4_M0 (enabled) vs PWM2_CH0/CH1_M2
 *   - To use PWM2_CH0/CH1: disable uart4, enable pwm2_8ch_0/1
 *
 * Pin 12 (GPIO0_B5) vs Pin 26 (GPIO2_C1):
 *   - Same hardware channel: pwm1_6ch_1
 *   - Pin 12 uses PWM1_CH1_M0 (enabled), Pin 26 can use PWM1_CH1_M2
 *   - To use PWM1_CH1 on Pin 26 instead: change pinctrl-0 to <&pwm1m2_ch1>
 *     and disable spi1 (Pin 26 is SPI1_CSN1)
 *
 * Pin 13 (GPIO2_C6):
 *   - Can use PWM1_CH5_M2, but shares hardware channel with Pin 35 (pwm1_6ch_5)
 *   - To use PWM1_CH5 on Pin 13: change pwm1_6ch_5 pinctrl-0 to <&pwm1m2_ch5>
 *
 * Pin 19/21/23/24/26 (GPIO2_C2/C3/C5/C4/C1):
 *   - SPI1_M1 (enabled)
 *   - Pin 19: also PWM1_CH2_M2
 *   - Pin 21: also PWM0_CH0_M2
 *   - Pin 23: also PWM1_CH4_M2, UART11_RX_M1
 *   - Pin 24: also PWM1_CH3_M2, UART11_TX_M1
 *   - Pin 26: also PWM1_CH1_M2, UART9_TX_M0
 *   - To use UART11: disable spi1, enable uart11
 *
 * Pin 22 (GPIO2_D6):
 *   - Can use PWM2_CH6_M2, but shares hardware channel with Pin 33 (pwm2_8ch_6)
 *   - To use PWM2_CH6 on Pin 22: change pwm2_8ch_6 pinctrl-0 to <&pwm2m2_ch6>
 *
 * Pin 27/28 (GPIO2_B7/B6):
 *   - I2C8_M2 (enabled) vs UART7_M0
 *   - To use UART7: disable i2c8, enable uart7
 *
 * Pin 29 (GPIO2_C0):
 *   - GPIO (default), can use UART9_RX_M0 or PWM1_CH0_M2
 *
 * Pin 33 (GPIO4_A7) vs Pin 22 (GPIO2_D6):
 *   - Same hardware channel: pwm2_8ch_6
 *   - Pin 33 uses PWM2_CH6_M0 (enabled), Pin 22 can use PWM2_CH6_M2
 *
 * Pin 35 (GPIO0_D2) vs Pin 13 (GPIO2_C6):
 *   - Same hardware channel: pwm1_6ch_5
 *   - Pin 35 uses PWM1_CH5_M0 (enabled), Pin 13 can use PWM1_CH5_M2
 *
 * Pin 37/40 (GPIO2_A6/A7):
 *   - GPIO (default) vs UART8_M1
 *   - To use UART8: enable uart8
 *
 * Pin 18/38 (GPIO3_A3/A2):
 *   - GPIO (default) vs CAN1_RX/TX_M3 vs SPI3_CSN0/MISO_M0
 *   - To use CAN1: enable can1
 *   - To use SPI3: disable i2c7 (pin 3/5), enable spi3
 */
