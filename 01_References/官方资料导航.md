立创上述以太网章节重点是自动获取地址，未据此确认当前板上持久化固定 IP 的配置文件或工具。识别实际网络管理方式后，使用对应的软件官方文档。

| 官方维护方 | 文档 | 适用条件与要点 |

| Microsoft | [Windows OpenSSH 入门](https://learn.microsoft.com/zh-cn/windows-server/administration/openssh/openssh_install_firstuse) | Windows 客户端连接与首次主机验证；本机已检测到 `ssh.exe` |

## 4. 当前资料如何用于开发

1. **先确认实物系统**：阅读对应串口章节，取得终端后读取系统版本、接口和现有地址。
2. **先建立可用连接**：经路由器连接可先沿用官方 DHCP 路线；直连则另行规划两端地址。
3. **再做固定 IP**：确定地址、冲突检查方式和网络管理工具，保存原配置，再进行持久化设置。
4. **完成实际验收**：Windows 登录成功，重启板卡后用同一 IP 再次登录，并保存日志。

具体执行准备见 [SSH 与固定 IP 配置准备](../02_Study_Notes/SSH与固定IP配置准备.md)。

首次操作先看 [首次上电与串口终端](../02_Study_Notes/首次上电与串口终端.md)。串口电平与物理针序仍需实物版本和原理图核对，常规 8N1、无流控设置也保留官网截图作为现场核对入口。
