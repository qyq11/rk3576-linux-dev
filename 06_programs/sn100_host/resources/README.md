# SN100共用界面资源

这里保存共用图片，主要供基础设置页与消息框引用。

[返回上级说明](../README.md)

## 文件用途

| 文件或目录 | 用途 |
| --- | --- |
| [arrow_drop_down.svg](arrow_drop_down.svg) | 下拉选择箭头矢量图。 |
| [close.png](close.png) | 关闭图标。 |
| [messagebox/](messagebox) | 消息框使用的图标资产。 |
| [上级resources.qrc](../resources.qrc) | 将这些文件编入程序，并定义程序中的资源路径。 |

各业务目录还可有自己的resources/和.qrc；修改资源前先查引用路径与alias，不能只改文件名。
