## 两种操作必须分开

现有`rk_board.sh`的`supervise()`从启动到应用退出一直持有`lifecycle.lock`排他锁；旧09暂存脚本也申请此锁，因此正式界面存活时旧暂存不能完成。不能为拿锁而停程序、解锁或重启主控。

新的只保存阶段只申请`immutable_store.lock`排他锁。它只创建本批独有的随机上传、私有解包目录和全新不可变版本目录，不写`current`、运行数据、资料指针、配置、显示或现有发布文件。前后记录`current`、现有运行身份和原主控身份；任一变化都保留现场并停止，不登记完整成功。独立存储锁只能串行采用本合同的新工具；唯一总控仍须保证不并行运行旧写入工具。

切换阶段由总控另行授权和串行安排：先在存储锁内将已核不可变包复制到全新的平层`releases/<新发布号>`，保留嵌套暂存原件；需要切换时由总控按真实身份安排旧应用停止。确认旧应用已退出后，按`immutable_store.lock → lifecycle.lock`顺序取锁，核同包、旧指针、无GUI/报告进程、原主控与配置仍一致，保存旧指针，再原子切换`current`。交接前释放本模板的生命周期锁和存储锁，不持父级运行锁启动新监督器。

同组无GUI/报告/检查进程、服务inactive/failed及VT/DRM无持有者条件必须在取运行锁前、取锁后和实际切指针前完整复核，不能拿早期快照或拿到锁本身代替。主控每次按basename含deleted排重，异路、重复或未知活进程拒绝；再核唯一实际exe/path/SHA及每条5000监听归属。读取前后完整身份一致才继续，拒绝时不停止任何进程、不释放显示、不重启服务。

切后只有总控负责唯一实际启动；状态窗口只实现同进程被动CPP、只读等待和结果解析，本窗口不写`run_case`或启动器。新被动CPP随未来程序链接，缺观察参数零干预；当前程序不注入、不附加、不启动第二界面。Root优先评估`supervise ... 0`加独立只读等待，但它仍有监督异常/信号TERM路径，不能称为任何失败都不关闭。旧`start 0`还多一条约30秒READY超时TERM，不能默认采用。观察封口不是应用退出，不补APP_EXIT或干净关闭通过。

## 与状态登录窗口共用的最小字段

以下字段语义按总控裁定v1对齐，真实值、源表、对象及动作许可仍待总控固定。观察schema为`sn100-lis-keep-running-observation-v1`。当前模板不实现第二套观察器，切换模板保持默认拒绝。

| 字段组 | 用途与要求 |
| --- | --- |
| 版本与作用域 | `format`、`batch_id`、`operation_id`、`phase`、`scope`。构建/文件暂存、切换、运行观察、业务检查分别记录，不让一个0代替其他结果 |
| 输入身份 | 最终审查、实际合入终态、完整起始/最终源码表、全部工具record，以及本次实际`build_complete`、`object_binding`和程序包record |
| 板卡 | `board`、`serial`、`host_fingerprint`、`boot_id`；现场重新读取，PID不能沿用旧时点 |
| 应用身份 | `pid`、`start_ticks`、`exe`、`exe_sha256`、`release_id`、`run_dir`、`ready`、`running`、`supervisor_duration_seconds`；前后同一现有应用，或切换后明确的新应用 |
| 主控身份 | `pid`、`start_ticks`、`exe`、`exe_sha256`及实际监听；不启动第二主控，不把原PID当永久活体身份 |
| 环境保护 | `current_before/after`，三份资料/配置指针的原文record，七份配置指纹清单record；核实际生效输入，不改INI凑通过，不收密码 |
| 动作许可 | 构建前cfg只固定`allow_full_build/allow_stage`。包后Root意图单独固定准备平层、切换、旧停止和唯一新启动许可；全部默认false，不回改已绑定cfg |
| 实际结果 | 内部CPP没有单独进程退出码；只读等待器与解析器分别记录真实`waiter_actual_exit`、`parser_actual_exit`。观察封口时`application_exit=null`，`application_exit_evaluated/shutdown_evaluated/close_verified=false`；未取得退出保持未知，不补0 |
| 留屏收尾 | `observation_complete`只表示快照封口；实际前后同一活进程、窗口存在/可见、current及配置不变分别采集。观察结束不关闭、TERM或超时清理；不拿这段观察代替实屏与未来长稳 |

运行身份记录的内容由真实板端读取者负责；本窗口的模板只约定来源与绑定，不能用自己在PC生成的JSON冒充板端观察。共享record固定后由总控纳入输入/归档。本候选不私加生产调试入口、进程注入或第二主程序。
