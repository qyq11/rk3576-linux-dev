## 下一步：读取系统和网络信息

在显示器上现有的 `lckfb@localhost:~$` 提示符后逐条输入命令，每条按回车；不用输入提示符本身：

```bash
cat /etc/os-release
uname -a
ip -br addr
ip route
```

以上为只读查询，不需要先安装桌面。若命令报错，保留原始提示。

同时确认网线当前连接方式：开发板直连 Windows 电脑、连接路由器 / 交换机，还是尚未接网线。依据实际结果选择网络方案，再检查 SSH 服务并配置固定地址。暂不预设板卡 IP、网关、网卡名或网络管理方式。
