## 先了解现在能用到哪一步

当前软件运行在RK上，但启动方式仍是脱机模式：可以管理本地资料、准备样本预设、处理匿名演示报告；尚不能完成“放样本 → 点开始 → 仪器检测 → 得到真实结果”的流程。页面里的“匿名完成”等记录是内置演示数据，不是这次操作产生的仪器结果。

按用户2026-10-27的新安排，**约定功能全部实现之后，再调整分辨率、适配小屏幕**。本轮保持现有尺寸；遇到右侧或底部看不全，先使用窗口最外层的横向、纵向滚动条。将遮挡、点不到、中文输入问题记录下来。

建议第一次按下面顺序操作：**医院保存/取消 → 试剂管理 → 瓶型 → 孔位设置 → 报告查询/编辑 → CSV/PDF → 正常关闭重开**。不要求先接仪器或配置通信。

### 两个决定能否继续测试的前提

1. **项目列表可能为空。**启动不自动添加项目/单位；新版可以从“项目管理…”先维护单位，再新建或导入已确认的配置，步骤见T17。没有有效的仪器编号、单位或测试方案时，相关检测前置仍未具备；不通过改数据库绕过。报告里的PT、APTT等来自独立匿名报告数据，不会自动成为可用项目。
2. **两个报告模式不同。**现在板端常用启动入口没有开启`--local-results`，用的是匿名演示历史，适合测试CSV/PDF/HTML。新原值模式和离线原始通信消息收件箱已有代码，但常用板端启动入口没有启用；Ctrl+Shift+I没有出现收件箱，不能直接当本轮故障。

## 怎样保存，保存到哪里

### 保存资料与导出文件是两件事

| 你正在做什么 | 必须点什么 | 何时算保存成功 |
| --- | --- | --- |
| 医院/字典 | 当前类别的“保存” | 等待提交及重新读取完成；仅“添加”一行还没保存。切类别前逐类保存 |
| 试剂资料、瓶型、批组 | 各自弹窗的“保存” | 等待操作结束并重开读到相同资料 |
| 试剂孔位 | “试剂设置”弹窗的“确定” | 回到盘面显示所选试剂；手工余量需另行录入 |
| 样本预设 | 外层“更新设置” | 架和孔位重开仍在；明细里的“设置”只是写回架草稿，还需点外层“更新设置” |
| 项目 | 右侧“保存”；结果表右键的配置窗另有保存 | 保存成功后重新选项目/重开读回；普通保存不代替结果显示配置窗保存 |
| 报告患者资料 | “详细”窗口里的“保存” | 出现患者资料已提交的反馈，再查询/打开仍一致 |
| 校准、质控、打印机、LIS | 各自“保存修改”“保存/确定”“应用/Apply”等提交按钮 | 等待成功反馈；规则选项保存不会产生检测结果 |
| 报告导出 | “导出”生成CSV；“打印”进入预览，再选Save as PDF/HTML | 文件生成完成且能在电脑打开核对内容 |

普通页面输入不会自动保存。成功保存的资料退出后应保留；未保存的草稿要明确保存或放弃。**取消不会撤销已经成功提交的新增、删除、关联或批次操作。**尤其医院字典删除已保存行会立即提交，测试时只删自己新增的测试行。

当前板端数据根为：

```text
/home/rkshare/programs/sn100_shell/runtime/data/
```

医院、账户、历史、项目等数据由程序分别保存；项目/试剂/样本共用`catalog/catalog.db`，质控和校准在各自目录。日常不需要手动操作数据库。

**CSV/PDF/HTML只能保存到当前历史目录的`exports`下，且必须是新的文件名：**

```text
/home/rkshare/programs/sn100_shell/runtime/data/history/exports/
```

文件选择框默认就在这里。先用`RK01.csv`、`RK01.pdf`、`RK01.html`，重复测试改为`RK02`，不要选择桌面或U盘目录，也不要覆盖同名文件。当前拒绝这些路径/覆盖属于已有约束。文件在RK上，不会自动出现到Windows电脑；可用SSH客户端的远程文件浏览功能下载单个导出文件。

CSV为GBK编码，中文乱码时按GBK/简体中文编码导入；PDF用电脑阅读器打开检查，HTML用浏览器打开。CSV不是全部业务数据库的备份，不能用它恢复账户、项目或样本架。质控、校准与项目库存在配套绑定，当前不要通过随意挪目录或单独复制某个库测试恢复。

## 第一轮：现在就可以做的测试

全用匿名测试内容。优先使用`RKTEST`、`KS01`、`RTEST01`等英文数字；中文输入另测。选空孔、自己新增的行和预设，避免覆盖已有内容。下面“应看到”是验收目标，请在实测后填写通过/失败/前置不具备。

### T01 页面与输入

1. 依次点击左侧八项：试剂设置、样本设置、结果报告、校准曲线、质量控制、分析项目、用户设置、仪器操作。
2. 应切换到相应页面，左侧选中状态一致；空列表可以为空，但不应崩溃、卡死或显示别页的资料。
3. 用最外层滚动条找到右侧和底部按钮；点击输入框，输入`RKTEST`，测试退格和Tab，再取消。
4. 如有中文输入法，再尝试输入“测试”。英文可输入、中文无法调出或选字，单独记为中文输入问题。

### T02 医院名称和五类字典保存

1. 点“用户设置 → 医院信息”，医院名称填`RKTEST`。
2. 点“科室信息 → 添加”，在新行名称填`KS01`，备注填`RK01`，点“保存”。名称最多6个中文、字母或数字，助记符由程序生成。
3. 等待保存/重读结束，切到别页再回来，应仍是`RKTEST`和`KS01`。
4. 按同样方法在“病人类型、送检医生、检验医生、审核医生”分别添加自己的测试行，每一类都点保存再切换。医生工号使用不超过6位的字母数字。
5. 留一条新增空白行，直接保存：应明确拒绝空名称，已有成功保存的资料仍在。然后取消并放弃这条空草稿。

### T03 取消与离页保护

1. 在医院名称末尾加`X`，不保存，点击“结果报告”。
2. 应弹出放弃未保存修改的确认。先点“保留更改”：应留在原页，`X`仍在。
3. 再切页，点“放弃并继续”；回到医院页，应恢复上次保存的`RKTEST`。
4. 再改一次，点页面“取消”，确认放弃后也应恢复已保存值。保留和放弃两条路径都要试。

### T04 字典修改与删除

1. 将T02自己新增的`KS01`改为`KS02`并保存；切页回看应为`KS02`。
2. 选中自己的测试行点“删除”，第一次在确认框点取消：行应保留。
3. 再删并确认：应立即删除并重新读取，切页/重开后不恢复。**只删除自己的测试行；此动作不需要再点保存，之后点取消也不能恢复。**

### T05 试剂盘选孔（对应照片上的页面）

1. 点“试剂设置”，依次单击`R_1`、另一个试剂孔、`SD_1`。
2. 应出现对应选中边框，中间信息栏标题随孔位变化；空孔的试剂可显示`none`，其他信息为空或未知。
3. 回选一个空的试剂孔，记录孔号；以下以空的`R_20`为例。选孔不应改变其他孔位资料。

### T06 新增试剂资料

1. 点右侧“试剂管理 → 新增”。名称`RTEST01`，厂家`TEST`，类型选“试剂”，勾选有效；警告量填`100`，缺少量填`20`，点保存。
2. 重新打开管理窗，应在列表找到该试剂并读回相同数值。这里只建资料，盘上的孔还没有自动绑定。
3. 改厂家为`CANCEL`，点取消：重新打开后应仍为`TEST`。
4. 将缺少量改为`200`、警告量保持`100`再保存：应拒绝，因为缺少量不能大于警告量；不应把旧的成功值改坏。取消草稿。

### T07 新增瓶型、给空孔设置试剂

1. 关闭管理弹窗，在试剂信息栏里**双击“容器”对应的瓶型值位置**，打开“本地瓶型字典”。空孔也可以从这个位置打开。
2. 选择新增，名称`BTEST01`，区域“试剂区”，最大容量`1000 µL`，高度`30 mm`，保存。这里只是匿名资料测试值。
3. 回到空孔`R_20`，点“试剂设置”（也可双击该孔），名称选`RTEST01`，瓶型选`BTEST01`，批次先用`Default`，有效日期填`2027-10-27`，点“确定”。
4. 应回到孔位信息并显示刚才选项；切到另一个孔再回来，应保持。试剂区只能选适用的有效试剂/瓶型，稀释液孔的候选不同。
5. 这次“确定”会把本地装载量和余量设为瓶型最大容量。**再次编辑孔位并确定也会重置这两个本地数值**，手工余量请在下一步单独设置。

### T08 手工余量、剩余次数和设备按钮边界

1. 选T07配置好的孔，**双击余量数值位置**，先输入装载量`800`并确定，再输入余量`600`并确定。
2. 切孔再回来，应读到本地余量`600`。它不是仪器液面探测值，也不会随真实检测自动扣减。第二个输入框点取消时，本次两步修改不应提交。
3. 点“剩余测试数”：当前没有消耗规则，应提示缺少配置/尚未接入，不应凭空出现可信测试次数。
4. “探测全部试剂、试剂盘扫描、试剂耗材、探测当前试剂、更换、优先使用、校准模式、默认盘面、清空盘面”等，当前要么禁用、要么只提示脱机未接入。点击没有仪器动作属于当前限制，**不能记作实际探测/换盘成功**。

### T09 样本预设基础保存（没有项目也可先测）

1. 点“样本设置”，点“＋”样本架图标，出现新的普通架草稿（例如`S01`）和8个孔。
2. 选第一行，双击样本号格，填`A001`，暂不选项目，点外层“更新设置”。
3. 切走再回来/点该架“编辑预设”，应保留架与样本号。该项只验证空任务预设，不能当检测任务已经具备。
4. 再把样本号改成`A002`但不更新，点返回或切页：应要求处理草稿；放弃后重开应为`A001`。
5. 不要把“清空预设”当取消；它会删除已经保存的普通预设，急诊架另有保留规则。删除自己的测试架留到最后。

### T10 查询匿名报告（先清空筛选条件）

1. 点“结果报告 → 查询”，先清空样本号和样本条码，取消“按日期查询”，点确定。
2. 应有匿名记录。**全新且尚未修改/删除的演示库有5条可见报告**；如果你已操作过，以当前资料为准。为空时先检查筛选，不要认定检测结果丢失。
3. 再查询，勾选按日期，开始和结束都选`2026/10/23`，其他条件仍清空，确定。未改动演示库应有3条。
4. 开始日期晚于结束日期时应拒绝查询，仍可纠正。样本号/条码框内残留文字也参与筛选，不能只取消勾选而不清空文字。

### T11 报告明细保存、字典选择和取消

1. 选中一条普通匿名报告，点“详细”，只修改“备注”为`RK_NOTE_01`，点明细里的保存。
2. 等待“患者信息已提交”一类反馈，关闭明细、重新查询再打开，应仍为`RK_NOTE_01`，检测数值不随备注变化。
3. 改备注为`CANCEL`但不保存，尝试关闭/切页；保留应留下草稿，明确放弃后再打开应是`RK_NOTE_01`。
4. 在明细“科室”输入框内**右键**，应打开已保存医院字典的选择窗；选择T02留下的条目并确认，再保存明细、重开核对。打开选择窗再取消，不应改变原字段。
5. 该字典完整路径在当前RK版本仍待实测，若失败请记录到哪一步。姓名、医生等输入框保留了原版较严格的长度/首字符限制，第一轮先用备注测试保存；被输入框拒绝的字符不要靠反复点击保存绕过。
6. 上传、重新计算、真实原始曲线等尚还没有接通完整流程，不作为本轮明细保存通过条件。

### T12 导出CSV

1. 先关闭已保存的明细；在报告列表左侧**勾选**一份报告。只有高亮当前行不等于勾选。
2. 点“导出 → 导出当前选中报告 → 确定”，保留默认目录，文件名填`RK01.csv`并保存，等待导出完成。
3. 下载该文件到电脑，按GBK打开，核对包含勾选报告的样本信息/项目和结果。一次复测可有多行，不能用文本行数简单当报告数。
4. 再试“导出当前查询报告”：应按当前筛选导出，不是只导出当前屏幕一页。
5. 取消文件框不应生成文件；不勾选时导出选中应提示没有选中数据；已有文件名应拒绝覆盖，改用`RK02.csv`。

### T13 预览、PDF和HTML

1. 确认医院名称已经保存、报告明细没有未保存草稿，选一条报告，点报告页“打印”。**此处先打开预览，不会立刻出纸。**
2. 应出现原报告模板，核对医院名称、样本和结果；尝试缩放/翻页。模板内容来自已保存值，不应取尚未保存的草稿。
3. 在预览工具栏点“Save as PDF”，默认目录下填`RK01.pdf`保存，等待结束。窄窗口找不到工具栏项时检查右侧展开箭头。
4. 下载到电脑打开，核对中文、数值、边界和分页。板端已有中文文件生成首验，但这个屏幕点击路径仍需本轮人工验证。
5. 同样用“Save as HTML”保存`RK01.html`，浏览器打开核对。当前源文字含`&`会明确拒绝HTML，记录提示，可改用PDF；不能默默缺字。
6. 取消不应留成品，同名文件不覆盖，导出期间切页/退出会受到保护。实体出纸另验：需要可用设备及标准确认，不能用“PDF生成了”代替。

### T14 本地设置、语言与告警边界

1. “用户设置 → 打印机设置”：有设备候选时选择并点应用/Apply，离页重开核对保存；没有设备就记为“无打印设备，未验正向选择”，不凭空填设备名。
2. “用户设置 → LIS设置”：可查看/编辑两种模式并保存意图；这一步不建立真实连接。第一轮只查看和取消，配置保存测试留待约定测试值后做，避免覆盖现有参数。
3. “用户设置 → 语言设置 → 应用”：应明确提示目前只支持简体中文，不应假装切换语言成功。
4. 顶部告警历史入口若可用，可查看日期区间；没有历史数据库/没有记录可以明确提示或为空。不得把空历史当“仪器没有故障”。实际告警/蜂鸣/复位没有接通。

### T15 正常关闭和重开：检查资料是否真正保存

在连接RK的终端内，以普通用户执行。已运行时不用再执行start；每次只复制一条命令。

查看状态：

```bash
bash /home/rkshare/programs/sn100_shell/sn100.sh status
```

先保存各页并关掉弹窗，再正常关闭：

```bash
bash /home/rkshare/programs/sn100_shell/sn100.sh stop
```

应看到正常关闭；如提示处理未保存操作，就回屏幕选择保存或放弃，再执行stop。**右上角红电源按钮当前禁用，不用它测试正常退出。**

重新打开：

```bash
bash /home/rkshare/programs/sn100_shell/sn100.sh start
```

依次核对：医院名、留下的字典、`RTEST01`、`BTEST01`、测试孔和余量、`A001`预设、`RK_NOTE_01`备注，以及已导出的文件。应保持最后一次成功提交的值，取消的草稿不能回来。当前没有开机自启动，重启RK后需手动start。执行失败时记录原提示，不删除数据目录重建。

### T16 账户与访客限制（放在最后）

1. 在“用户设置 → 账户设置”查看当前匿名账户；新增时留空用户名/密码点增加，应明确拒绝，列表不应增加空账户。不要改当前管理员密码或删除当前测试身份。
2. 处理完所有草稿，点顶部“注销”，应清除当前会话；部分项目/试剂写入入口禁用，访客不能通过按钮绕过保存。
3. 医院页等历史页面并没有统一相同的角色门槛，因此不要把所有页都要求成相同禁用状态。这只验证现有规则，完整生产权限仍待明确。
4. 当前命令start使用匿名测试管理员；需要恢复演练身份时，正常stop后再start，不猜测生产密码。若要测试真正的本地密码登录，应另建自己掌握密码的测试账户；密码不写入反馈或截图。

## 第二轮：有项目资料后再做

以下先决条件不具备时直接记“前置资料缺失”，不要算通过，也不要求本轮补资料或改程序。

### T17 空库新建/导入项目，再保存、取消和复制

前提：当前是可操作的工程师或管理员，有已确认的项目编号、单位及方案资料；只对自己的隔离测试项目操作。没有有效资料时，不把临时测试值用作临床配置。

1. 点“分析项目→项目管理…→单位维护”，填名称与正整数倍率，点“新增”等待读回。倍率用于结果换算，按有效资料填写。未引用单位可以修改/删除，已被项目或业务引用时应拒绝；收到成功回执后已提交，关闭弹窗不会撤销。
2. 回到“项目管理…→新建项目”，填项目名称、全称和明确的仪器项目编号；为窗中四类结果逐行选择单位并确认启用/显示。点“进入编辑”只建立草稿，再点原右侧“保存”才写入。新建后点“取消”应不新增项目。
3. 已有配置文件时点“项目管理…→导入项目配置…”，选择明确的UTF-8 JSON。文件使用`sn100-project-config-v1`格式，字段约定见[本批接口说明](../../04_references/sn100_host/project_config_20261027/contracts/data/contract.md)。只追加，不覆盖同名项目/单位；格式或任一记录失败时整批拒绝，不把参考数据库当导入文件。
4. 选测试项目，修改后点“保存”，切走再回来应保留；再改一个字段点“取消”，应恢复最后提交值。“复制新增”输入唯一名称后应选中副本，修改副本不能改变原项目。普通独立项目可以删除；固定或被其他业务引用的项目应拒绝。
5. 系数A/B/C要一起填写，范围-9999至9999、最多4位小数；全空表示未配置。部分空或非法值应拒绝保存并保留输入。三个结果“启用”与结果是否显示、哪个是主结果分别保存。原分析方法/采样频率只读、校准页及自动应用尚未开放；保存系数不会执行完整算法或校准应用。
6. 在“稀释比例”用原“添加/删除”维护方案名称、选用和已确认的动作参数；在“测试方案”从已选用方案里明确选默认和有效稀释液。删除默认而仍有其他方案时，应先重选再保存；没有方案表示尚未配置，不能据此认定项目能检测。保存后核对全部行和默认，未保存增删后点取消应完整恢复。
7. 保存失败时先看原提示，输入应保留；解除原因后再保存。写入成功但读回失败时从“项目管理…→重新读取”恢复，不能继续用旧画面覆盖。按T15关闭重开，核对项目、单位、系数、稀释/默认与稀释液。
8. 基础和高级草稿先保存或放弃，再在结果表右键选“配置结果显示…”，明确配置主结果、选用/显示、单位和小数位，保存、重开核对。当前匿名报告来自独立演示契约，不要求项目修改后匿名报告立即跟着变；真实检测与检测时保存的单位仍另验。

### T18 样本项目、明细和组合

前提：有已启用项目及有效的稀释候选。使用T09自己新建的架。

1. 编辑架，选第一孔`A001`，在项目区选择一个测试项目，次数选`1`。
2. 点“样本测试设置”查看/调整该孔的容器、次数及已存在的稀释选项；明细点“设置”后，再点外层“更新设置”。切页重开应保持。
3. 普通组合：点“配置多项测试”，新建自己的普通组合、选择成员并明确保存；再应用到架，检查有序项目及次数，点更新设置保存架。
4. 多瓶模式仅保存设置，应用到架应明确拒绝且保留原草稿；“同步任务”没有真实LIS下载，开始/暂停不应运行检测。没有状态前提时，不人为制造“测试中/已完成”去验复测。

### T19 质控品、批号与单孔预设

1. 点“质量控制 → 质控品管理”，新增自己的`QTEST01`、厂家`TEST`并明确保存；重新打开应存在。
2. 有可用项目时，在项目选择窗勾选并确认，关联才提交；取消选择窗不改关联。保存靶值/规则只保存资料，不判定结果。
3. 选控制品点“设置批号”，填唯一测试批号`QLOT01`和有效期后保存。新增其他批次用表格右键“新增批次”或Ctrl+N，不把编辑旧行当新增。
4. 在样本单孔明细选质控类型，选择控制品与批次，核对自动关联项目；明细“设置”后再点架的“更新设置”，重开核对。
5. 新库没有检测历史，空图是预期，不能要求自动生成质控曲线。已有历史单位未知时可显示原值，但均值/标准差/变异系数为不可用；不把未知数据套上当前单位。

### T20 校准原始点

前提：已启用的测试项目具有保存完整的“浓度结果单位”和“原始测试单位”，有编辑权限。

1. 点“校准曲线”，选择该项目，在曲线列表右键“新增本地原始点记录”（也可按Insert）。
2. 校准品批号填`CLOT01`，不关联试剂批次，点数`3`、每点重复`2`；只为本地存取演练。
3. 按表头所示单位，浓度依次填`1、2、3`，每行两次测试值分别填`10/12、20/22、30/32`，点“保存修改”并确认。
4. 重选记录应保留输入，均值散点分别对应`11、21、31`；反算值不应假装已有结果。记录应保持未拟合、未审核、未应用。
5. 改一点后取消应恢复已保存点。复制保存记录应出现新本地记录；“删除曲线”是隐藏而非清除原始记录，第一轮可不做删除。

## 仪器维护页面如何理解

“仪器操作”里的状态/版本等可见子页可以切换查看，实际温度、传感器、通道值没有来源时应是未知/空，不应假显示正常。泵阀、混匀、洗针、自测、连接、关机等设备动作目前禁用。

人工维护记录只是“人完成维护后，登记今天做过”。如果以后要试登记，可在“仪器维护”里选一项人工维护操作，第一次取消应不增加记录，明确确认后应在今天对应格出现勾选，换月再回来仍存在。**当前没有实际做维护时先只测取消，不确认登记**；点按钮不会替人完成维护，长期清洗和设备关机也不是本地人工登记的替代。

## 怎样反馈，什么才算通过

每个用例记录“通过 / 失败 / 前置不具备 / 尚未测”。**已知禁用的设备功能、空项目阻挡和真正异常分开记录。**一项保存至少检查“本页读回 → 切页回来 → T15关闭重开”；只有最后一步通过，才算验证了跨进程保留。

可复制下面格式回复：

```text
用例：T07
结果：失败
操作：R_20 → 试剂设置 → 选RTEST01/BTEST01 → 确定
预期：回到孔位信息并显示试剂
实际：……（原提示、是否能继续操作）
重开后：……
照片：记录发生时间和页面，避开密码及真实患者资料
```

初次编写本说明时只核查代码/部署资料并交付人工步骤，没有执行以上屏幕操作或改动应用/数据；后续项目配置的直接RK结果已在首部和T17更新，其余人工用例仍按各自待验范围理解。核查依据：`shell/rk_board.sh`及`rk_control.sh`（启动模式/退出）、`projects/project_page.cpp`和`projects_store.cpp`（项目入口/空库初始化）、`reagents/reagents_page.cpp`及`reagent_store.cpp`（照片按钮/资料规则）、`samples/sample_page.cpp`及`sample_store.cpp`（草稿/保存）、`history/history_page.cpp`、`history_store.cpp`及`report_controller.cpp`（查询/明细/输出）、`tests/fixtures/history_reports.json`（匿名日期/数量）、校准/质控/仪器操作正式页面，以及[既有功能分析](sn100_host_function_and_porting_review.md)。实际记录继续追加[同一移植记录](../../02_records/20261022_sn100_host_migration.md#manual-test-guide-20261027)，待办在[原计划](../plans/sn100_host_migration_plan.md#rk-offline-card)维护。
