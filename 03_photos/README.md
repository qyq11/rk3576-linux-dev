## 原图、标注图与验证范围

`.jpg/.png`可直接查看，`.svg`可继续修改文字和框线。名称含“圈注”“marked”或“annotated”的是标注版本；原图与标注图各有用途。SN100原文件说明中完整PNG/SVG是48项总图，`all_part_01`至`03`是便于阅读的分图，`无标题.png`是用户最初提供的旧标注，最新用途说明以[原文件说明](../01_docs/knowledge/sn100_original_bin_files.md)为准。

历史图片保留拍摄或测试当时的范围：电脑截图不等于RK实屏照片，界面出现不等于功能或真实仪器验证通过。实际结果继续查看[操作记录](../02_records/README.md)。

## 旧路径怎么找

2026-10-27初次分类只移动文件；随后按用户要求删除独立Qt显示示例的20张图片及其当前导航，保留文件的内容和修改时间不变。日常说明中的图片链接已更新；`04_references`、`07_backups`及带文件指纹的历史来源清单保留原文。

若旧清单记录的是`03_photos/文件名`，在[文件移动对照](文件移动对照.json)搜索该文件名：`old_path`是原路径，`new_path`是现在的位置，`sha256`是文件内容指纹。核对历史校验清单时，用新位置的文件与原指纹比较。来源清单与对应图片放在同一个功能文件夹，不改清单里的历史路径。

需要撤回分类时，先确认对照表中的新文件内容仍与指纹一致，再按对照表逐个移回原路径；原路径已存在文件时先核对，不能直接覆盖。今后新增图片按内容放入已有类别，保留日期；新事项确实不适合现有分类时再建中文文件夹。
