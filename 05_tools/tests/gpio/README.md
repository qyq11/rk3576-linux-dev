# GPIO输出实验

用一个C程序控制一个指定40Pin引脚，配合万用表核对高低电平。

[返回上级说明](../README.md)

## 文件用途

| 文件或目录 | 用途 |
| --- | --- |
| [gpio_output.c](gpio_output.c) | 引脚映射、libgpiod设备核对和交互输出；输入0/1设置电平，q退出。支持范围写在源码中。 |

2026-11-03已增加排针12脚：`GPIO0_B5`，`gpio0`控制器内偏移13。板A已停用该脚PWM，ARM64程序在板A输出低→高→低的内核读回通过；这不是电压测量或485通信验收。板A可运行`sudo /home/rkshare/programs/gpio_pin12_board_a_20261103/gpio_output 12`，启动先保持低电平，再按提示输入0、1或q。退出后不保证保持输出；输入模式可用`sudo gpioget gpiochip0 13`申请并读取。不要同时运行两个程序申请同一根线。

接线、构建及历史实测见[GPIO记录](../../../02_records/20261021_gpio_output.md)。软件打印的设置值与万用表实际电压分别核对；不要从引脚用途名称推定已连接了LED或负载。
