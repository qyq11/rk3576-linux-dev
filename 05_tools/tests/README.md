# 接口、系统与上位机测试

按测试对象找对应子目录：引脚输出、串口回环、系统实时性或上位机操作。SN100内部业务测试源码留在正式工程自己的tests目录；用户提供的上机测试程序和流程文件集中放在下面的sn100_host目录。

[返回上级说明](../README.md)

## 文件用途

| 文件或目录 | 用途 |
| --- | --- |
| [gpio/](gpio/README.md) | 控制指定引脚并配合万用表测量。 |
| [uart/](uart/README.md) | UART4本机发收回环。 |
| [can/](can/README.md) | CAN控制器内部回环源码与ARM64编译入口；RK结果查对应CAN记录。 |
| [preempt_rt/](preempt_rt/README.md) | 普通/实时内核延迟测试和结果绘图。 |
| [sn100_host/](sn100_host/README.md) | 上位机测试程序和流程文件；SN500完整包在板B直接复测仍读取key.ini失败退出，与作者所说的无需此文件不一致，待核程序版本或启动方式。 |

执行前先读对应记录里的接线、设备、权限和测试条件；本次补说明没有运行硬件实验。
